Customer Spending & Catalogue Purchase Analysis

Project Overview

This project analyses customer characteristics and spending patterns to understand factors associated with catalogue purchases using R programming and statistical analysis.

Objectives

Analyse customer demographic and spending information.

Identify relationships between customer characteristics and catalogue purchases.

Build and compare multiple linear regression models.

Evaluate model performance and identify relevant predictors.

Dataset

Original records: 1,000 customers

Complete records retained after missing-value removal: 697

Variables included age, gender, marital status, salary, home ownership, children, customer history, catalogue purchases and amount spent.

Tools & Techniques

Programming: R

Data Preparation: Data cleaning and categorical label encoding

Statistical Analysis: Correlation analysis and multiple linear regression

Model Evaluation: R-squared, residual analysis and Variance Inflation Factor (VIF)

Key Findings

Compared multiple linear regression models to analyse catalogue purchases.

The final model reported an R-squared of 26.41%.

VIF values were below 5, indicating no serious multicollinearity concern among the predictors assessed.
